# Clicker Game

A small browser clicker game. Open `index.html` in a browser to play.

## Publish with GitHub Pages

1. In this repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose the `main` branch and `/ (root)`, then click **Save**.
4. Wait for the deployment, then open the Pages URL shown on that settings page. It will usually be `https://bc7525930-web.github.io/Clicker-game-/`.

The game stores accounts and progress in the current browser using local storage. This is a demo and does not provide secure authentication or shared data across devices. The bot leaderboard entries are simulated. The owner panel credentials are visible in the source; do not use a real password or treat this as secure admin access.
